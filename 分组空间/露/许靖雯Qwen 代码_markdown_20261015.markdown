## 二、轮次 1：原"选题四"完整设计（生成式 AI × 人文知识生产）

**核心思路**：用文献计量摸清"学界在讨论什么"，用政策文本看清"制度在管什么"，两者对照找出落差。

**推荐题目**：《生成式人工智能介入人文知识生产的伦理议题图谱与规范落差研究》

**研究问题**：
- RQ1 分布：2015—2025 年国内外研究格局与中外差异
- RQ2 结构：议题可聚为哪几类簇，哪些是持续热点、新近涌现、长期薄弱
- RQ3 落差：学界高频议题与已出台规范的覆盖重合度

**数据**：CNKI + WoS/OpenAlex 题录；中文社科期刊 AI 使用声明、机构科研诚信办法、COPE 等国际政策。

**方法**：CiteSpace / VOSviewer / Bibliometrix 计量分析 + 8 维伦理议题编码（作者署名、事实性与幻觉、证据链与可复核性、偏见与代表性、数据与版权、透明披露、责任归属、能力与主体性）+ 双人独立编码与 Kappa 检验。

**亮点切口**：自我指涉反思（用 AI 研究 AI 的伦理）、落到古籍与图情场景、中外治理逻辑对比（限制型 vs 透明型）。

## 三、轮次 2：学科归属定位

- 一级学科：信息资源管理
- 二级/方向：情报学（主）+ 数字人文（交叉）
- 研究领域：科学计量与文献计量、学术评价与科研诚信、信息伦理与法律
- 对应课程：图书情报学研究方法、情报分析与研究、图书情报职业伦理与法律
- **图情身份三锚点**：方法锚点（文献计量）、问题锚点（信息伦理与学术规范）、场景锚点（知识组织与信息服务）
- 风险提示：若通篇只谈"伦理原则该不该建立"，易被判为图情属性不足

## 四、轮次 3：转向档案学（因组内 3 人为档案学方向）

**原则**：换对象、不换方法。骨架（文献计量 + 政策文本 + 内容编码）保留，对象改为档案领域。

**权威依据**：
- 《全国档案事业发展"十五五"规划》：拓展"人工智能+档案"，安全稳妥有序推进，强化算法风险研判与监测
- 国家档案局《关于推进人工智能在档案行业应用的意见》：稳妥探索应用、确保安全保密；明确典型场景；要求应用结果须经业务部门审核确认
- 国家档案局 57 个人工智能应用试点项目（2026 年 7 月公布）；**苏州市档案馆入选**
- 学术先例：王玉珏等《人工智能生成合成内容的可信存档策略研究——基于对电子档案"四性"的思考》（《北京档案》2025 年第 4 期）

**备选方案**：A. AIGC 归档困境与规范建构（推荐）；B. 政策—实践落差研究；C. 开放审核人机协同与责任边界（需访谈，风险高）

## 五、轮次 4：方案 A 详版（后被判定过重）

包含：8 维政策编码框架、57 个试点项目数据库与深度编码、双人独立编码 + Kappa、生成溯源元数据字段表、10 周排期。

**问题**：接近硕士学位论文工作量，不适合课程作业。

---

## 六、轮次 5—6：简化与定稿

**砍掉**：试点项目数据库、双人信度检验、多份地方政策、独立元数据交付物、访谈。

**保留三样**：
1. 文献计量（150—250 篇，3 张图）
2. 政策文本 5 维度粗编码 + 覆盖统计表
3. 结论 + 3—5 条具体建议

**周期**：6 周；**交付**：5000—7000 字报告 + 图表 + PPT。

## 七、轮次 7：课程相关度评估（约 70%）

| 课程模块 | 覆盖情况 |
|---|---|
| 数字人文导论与范式 | 部分 |
| 数据获取、清洗与结构化 | 弱 |
| 文本挖掘（词频、主题模型、NLP） | 缺失 |
| 社会网络分析 | 缺失 |
| 空间人文 / GIS | 缺失 |
| 数据可视化 | 仅计量图谱 |
| 元数据与知识组织 | 仅一句 |
| 文化遗产 / 数字记忆 | 强 |

**问题诊断**：档案线强，"数据科学"与"人文对象"两线弱。

**两种提升路径**：
- 改法 A（最小改动）：质性编码 → 计算文本分析（Voyant Tools / AntConc / LDA），相关度约 80%
- 改法 B（相关度最高）：换人文对象（公开古籍/方志、CBDB），做词频 + 共现网络 + 可视化

---

## 八、轮次 8：提高相关度的三处修改

| 改动 | 原 | 新 |
|---|---|---|
| ① 方法升级 | 政策条款质性编码 | 质性编码 + 计算文本分析（词频、关键词、共现，可选 LDA） |
| ② 语料扩容 | 仅 2—3 份政策文件 | 政策 + 文献摘要 + 8—12 个公开案例描述，合并语料 |
| ③ 落点转向 | 政策建议为主 | 数字人文阐释为主（记录可信性、记忆形成与留痕），建议作落点 |

修改后覆盖 7 个课程模块中的 6 个，相关度提升至 90% 以上。

## 九、轮次 9：四个候选选题比较

| 维度（权重） | ① 修复隐性知识显性化 | ② 古籍智能处理+知识图谱 | ③ AIGC 辅助特藏开发与编研 | ④ AI+档案议题与记录可信性 |
|---|---|---|---|---|
| 数据易得性（30%） | ✗ 需进馆/访谈 | ✗ 全文多付费库 | ✓ | ✓ |
| 准备时间（20%） | ✗ 田野周期不可控 | ✗ 以月/年计 | △ 范围大易超时 | ✓ 6 周可交付 |
| 课程相关度（30%） | ✗ 缺计算与人文数据 | ✓✓ 最高但不可行 | ✓✓ 高 | ✓ 高 |
| 研一可行性（20%） | △ 依赖外部配合 | ✗ 需工程能力 | △ 需收窄 | ✓ 四线并行 |
| **结论** | 不推荐 | 不推荐 | 备选/可合并 | **推荐** |

**放弃理由**：
- ①：数据不在组内，机构准入难；偏质性知识管理，与课程匹配度最低
- ②：课程相关度最高但必然做不完，一学期只能出玩具级 demo
- ③：题目好且贴合人员结构，但横跨两个业务领域，"工作流"隐含实务验证，易写成两个半截综述

**最终策略**：以 ④ 为骨架，吸收 ③ 的"档案编研"场景，将泛谈"AI+档案"收窄到编研与著录标引。

## 十、最终敲定选题

### 题目

**《AIGC 介入档案编研的记录可信性问题——基于文献计量与文本计算的分析》**

（备选宽表述：《"人工智能+档案"的议题结构与记录可信性——基于文献与文本的计算分析》）

### 研究问题

1. **议题结构**：2018—2026 年档案学界"AI × 档案管理/编研"讨论集中在哪些议题？2023 年后新增了什么？
2. **规范覆盖**：现行国家层面政策对"生成过程留痕、人工审核与责任、披露与标识"覆盖程度如何？
3. **缺口与建议**：在电子档案"四性"框架下，AIGC 归档需补充哪些可操作的管理动作与元数据字段？

### 数据来源（全部公开）

| 数据 | 来源 | 量级 |
|---|---|---|
| 文献题录 | CNKI：「档案/电子文件/电子档案」×「人工智能/大模型/生成式/大语言模型」，2018—2026 | 分析集 150—250 篇 |
| 政策文本 | 国家档案局 AI 应用意见全文、"十五五"规划 AI 段落、1 份江苏/苏州公开表述 | 3 份 |
| 案例描述文本 | 公开报道与官网的档案 AI 应用案例（智能开放审核、智能著录、智能查档问答等） | 8—12 例 |
| 实证素材（可选） | 一段公开著录信息/编研素材，用公开大模型处理后人工核对差错 | 1 组 |

**明确不做**：进馆调研、访谈、内部数据、知识图谱构建、需授权材料。

### 方法

1. **文献计量**：CiteSpace / VOSviewer，出年度趋势、关键词共现、聚类或突现词 3 张图
2. **计算文本分析**：语料清洗（统一繁简、去噪、分段）后用 Voyant Tools 或 AntConc 做词频、关键词、共现；有余力加 LDA（3—5 主题）
3. **议题—维度覆盖分析**：议题簇 × 5 个可信性维度（数据基础／应用场景／算法与安全／人工审核与责任／披露与留痕），出覆盖强度表

编码方式：两人共同编码、分歧讨论定稿，方法部分说明为协商式编码，不做信度检验。

### 四人分工

| 成员 | 方向 | 任务 |
|---|---|---|
| 甲（档案学） | 语料与规范 | 政策与案例文本收集、清洗合并；5 维度编码与覆盖表 |
| 乙（档案学） | 理论与阐释 | 精读 15—20 篇核心文献；搭建"记录可信性/数字记忆"框架；撰写结果解释 |
| 丙（档案学） | 写作与统稿 | 文献综述、结论与 3—5 条建议、统稿与格式引用 |
| 丁（图情/情报学） | 计算与可视化 | 检索式设计与试检、导出清洗、计量图谱、文本分析、全部图表、方法部分 |

### 6 周排期

| 周次 | 内容 |
|---|---|
| 1 | 定题、检索式试检（用 3 篇已知文献验证可检回）；确定语料清单 |
| 2 | 正式检索、导出去重；下载政策原文；收集案例文本 → 数据全部到位 |
| 3 | 丁做清洗与计量图谱；甲做语料合并与编码；乙读文献 |
| 4 | 丁出词频/共现/主题结果；甲完成覆盖表；乙写分析框架 |
| 5 | 合写发现与人文阐释；丙起草建议（可选实证在此周完成） |
| 6 | 统稿、图表定稿、PPT（10—12 页）与预演 |

### 交付物

- 研究报告 5000—7000 字
- 可视化图 5—6 张（计量 3 张 + 文本分析 2—3 张）
- 议题—可信性维度覆盖表 1 张
- 汇报 PPT 10—12 页
- （可选）AIGC 归档溯源元数据字段建议 5—6 项

### 风险与规避

| 风险 | 规避 |
|---|---|
| 政策原文版本/日期引错 | 一律以官网原文为准，记录文号与发布日期，禁止转引自媒体 |
| 检索漏检或过宽 | 第 1 周必须试检，用已知高被引文献做检回检验 |
| 写成政策复述无发现 | 每条结论对应一张图/表，并回答"意味着什么缺口" |
| 建议空泛 | 写到"谁、在哪个环节、做什么、留什么痕" |
| 工具成为阻塞项 | 全组不会编程则走 Voyant + Gephi + VOSviewer 图形界面路线 |
