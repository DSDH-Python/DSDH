# 课堂游戏

本书为每个方法模块配了一款 **单文件 HTML5 小游戏**——零依赖、双击即开，可课堂投影，也可课后自测。

每款都挂着全书的方法论承诺，并内置 **伦理红线** 机制：踩线即扣分并弹出告诫，把"伦理在场"变成可玩的硬约束，而不是口号。

> **课堂节奏**：每款建议 **5–10 分钟**。页面顶部有实时计时，会提示「节奏合适 / 偏快 / 已超时」；底部有本机排行榜（数据只存本机浏览器，不上传），可记录姓名、得分与用时。

## 伦理红线总览（九款通用）

以下任一行为都会触发红线：判负或扣 3 分，并弹出对应告诫。

- 未授权采集在世社群数据，或未取得馆藏授权就使用 / 公开影像资料
- 把「需授权 / 禁商用」的数据当作「公开可商用」
- 用玩具数据或编造证据粉饰结论
- 替任何社群"代言"，或把数据缺失当作"该群体不存在"
- 把黑箱模型 / 图谱的低置信推断直接当作人文结论采信

## 课堂使用建议

1. **课前 / 课后自测**：让学生独立完成，用排行榜记录成绩与用时。
2. **课堂破冰**：挑 1–2 款做小组对抗（如模块三流水线、模块五修辞法庭）。
3. **复盘要点**：游戏结束后一定要回到 Rubric 的四个维度讨论——尤其是"伦理红线"那一栏，问学生"为什么这个选择会踩线"。
