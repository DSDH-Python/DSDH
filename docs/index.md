# 数据科学与数字人文

本课程由 **12 个方法模块与 1 个综合项目**构成，沿着“人文问题 → 数据 → 方法 → 知识 → 综合研究”的路径展开。数字教材以可复现、真实案例与研究伦理为贯穿原则。

## 课程体系

| 阶段 | 章节 | 内容 | 在课程中的作用 |
|---|---|---|---|
| 导论 | 第 1 章 · 当数据科学遇见数字人文 | 学科范式、方法论与伦理坐标 | 建立问题意识与研究规范 |
| 数据基础 | 第 2–3 章 · 人文数据；Python 与 pandas | 数据类型、获取、清洗与复现 | 准备可计算、可追溯的数据 |
| 分析方法 | 第 4–10 章 · NLP、可视化、网络、GIS、视觉、知识图谱、机器学习 | 文本、关系、空间、图像与模型分析 | 选择并评估适配研究问题的方法 |
| 智能技术 | 第 11–12 章 · 生成式 AI 与人工智能前沿 | 提示、RAG、智能体、多模态与治理 | 在可信边界内使用新技术 |
| 综合研究 | 第 13 章 · 综合项目与课程反思 | 组合至少两种方法，完成研究与答辩 | 形成可复现、可解释的研究成果 |
