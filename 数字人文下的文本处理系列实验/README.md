# 数字人文下的文本处理系列实验

本目录汇集数字人文与中文文本处理相关的九个实验，内容从汉字图像处理、分词和序列标注，延伸到预训练语言模型、知识图谱、文本分类与聚类，以及机器翻译。各实验的代码、数据和运行环境相对独立，请结合对应的实验讲义和目录说明使用。

## 实验目录

| 实验 | 主题 | 目录内容与说明 |
| --- | --- | --- |
| 1 | 汉字处理与篆体字识别 | 包含简繁转换、篆体字图像处理与识别相关代码、字体文件和过程记录。详见[实验说明](./实验1汉字处理/README.md)及[实验讲义](./实验1汉字处理/实验1%20汉字处理.pdf)。 |
| 2 | 汉语分词 | 面向非物质文化遗产文本的自动分词系统。详见[实验说明](./实验2%20汉语分词/README.md)及[实验讲义](./实验2%20汉语分词/实验2%20汉字分词.pdf)；说明中提供了系统源码和可执行文件的下载方式。 |
| 3 | 词性自动标注 | 提供 HMM、CRF 和 BiLSTM-CRF 序列标注实现及相关数据。详见[实验说明](./实验3词性自动标注/README.md)及[实验讲义](./实验3词性自动标注/实验3%20词性自动标注.pdf)。 |
| 4 | 命名实体识别 | 包含数据预处理，以及 BiLSTM-CRF 和 BERT 命名实体识别实现。详见[实验说明](./实验4实体识别/README.md)及[实验讲义](./实验4实体识别/实验4%20命名实体识别.pdf)。 |
| 5 | 模型预训练 | 包含 BERT 类语言模型预训练代码，以及将模型文件由 bin 转换为 TensorFlow ckpt 格式的脚本。详见[实验说明](./实验5%20模型预训练/README.md)及[实验讲义](./实验5%20模型预训练/实验5%20模型预训练.pdf)。 |
| 6 | 知识图谱构建及应用 | 提供 Flask 应用和检索相关模块；完整代码与数据见[关联项目 ZUOZHUAN_KBQA](https://github.com/veigaran/ZUOZHUAN_KBQA)。详见[实验说明](./实验6%20知识图谱构建及应用/README.md)。 |
| 7 | 文本分类 | 以非物质文化遗产文本为例，使用 RNN 进行文本分类。实验说明还链接了机器学习和深度学习分类示例。详见[实验说明](./实验7%20文本分类/README.md)及[实验讲义](./实验7%20文本分类/实验7%20文本分类.pdf)。 |
| 8 | 文本聚类 | 基于 K-means 的文本自动聚类实验，目录中附有相关数据。详见[实验说明](./实验8%20文本聚类/README.md)及[实验讲义](./实验8%20文本聚类/实验8%20文本聚类.pdf)。 |
| 9 | 机器翻译 | 使用 OpenNMT 探索古汉语到现代汉语及英语的自动翻译，目录中包含相关代码和样例数据。详见[实验说明](./实验9%20机器翻译/README.md)及[实验讲义](./实验9%20机器翻译/实验9%20机器翻译.pdf)。 |

## 使用建议

1. 先阅读对应实验的 PDF 讲义和目录中的 `README.md`，了解实验目标、数据格式和操作步骤。
2. 进入对应实验目录查找代码和数据；若说明中提到外部下载或关联仓库，请按该说明获取完整材料。
3. 各实验使用的框架和依赖版本并不统一。请根据各自说明单独配置环境，不要假定存在适用于全部实验的统一安装步骤。
4. 预训练、深度学习和知识图谱实验可能需要额外模型、数据或硬件资源；运行前请确认相关依赖和文件已准备齐全。
